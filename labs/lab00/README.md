# Вводная документация

Репозиторий для оформления практических работ курса.

## Структура

Каждая работа лежит в отдельной папке `labs/labNN/`:

- `README.md`: задание, решение, проверка;
- `configs/`: итоговые конфигурации устройств;
- `labNN.unl`: файл стенда для EVE-NG с конфигурациями;
- `*.png`: схемы.

## Стенд

Все работы выполняются на одном стенде в EVE-NG: роутеры Cisco IOL 15.4 (L3), коммутаторы Cisco IOL 15.2 (L2), хосты VPCS.
